StudySync is a full-stack, real-time peer-accountability study platform engineered to solve student focus and discipline challenges. By utilizing the Google Gemini Multimodal Vision API, StudySync automatically verifies focus sessions in 5-minute increments, categorizing sessions as productive or off-task without human intervention.

To create an engaging collaborative environment, the platform orchestrates 3 concurrent real-time systems built on top of Socket.IO and LiveKit WebRTC:

  • Live Cohort Leaderboard: Dynamic, real-time rank tracking calculated from verified focus hours and study streaks.
  • Cohort Group Chat: Low-latency websocket messaging for peer motivation and topic discussions.
  • WebRTC Voice Co-Working Rooms: High-performance audio channels for distraction-free group study sessions.

Built with React, TypeScript, Node.js, Supabase (PostgreSQL), and Tailwind CSS, StudySync was deployed to production with over 150+ commits across the development cycle.

Key Architectural Highlights

• Automated Vision Classification: Periodic snapshot evaluation via Gemini API to distinguish active studying from distractions.

• Low-Latency Real-Time Infrastructure: High-concurrency socket channels delivering sub-second state sync across active cohorts.

• Robust Data Layer: Supabase PostgreSQL backend structured with optimized schemas and row-level security.
